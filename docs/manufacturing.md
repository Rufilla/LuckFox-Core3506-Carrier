## Stack-up

JLCPCB **JLC04161H-3313**: 4 layers, 1.6 mm, ENIG. Values below are JLCPCB's; the KiCad board
stack-up rounds them.

| Layer | Thickness | Use |
|---|---|---|
| F.Cu | 35 µm (1 oz) | Signals & components |
| Prepreg 3313 | 0.0994 mm, εr 4.05 | |
| In1.Cu | 15.2 µm (0.5 oz) | GND plane |
| Core | 1.265 mm, εr 4.6 | |
| In2.Cu | 15.2 µm (0.5 oz) | 3.3 V & 5 V planes |
| Prepreg 3313 | 0.0994 mm, εr 4.05 | |
| B.Cu | 35 µm (1 oz) | Signals |

## Impedance control

Net classes are calculated for microstrip on F.Cu over the In1.Cu GND plane.

| Net class | Track width | Pair gap | Target |
|---|---|---|---|
| DSI | 0.09 mm | 0.13 mm | 100 Ω differential |
| Ethernet (MDI) | 0.09 mm | 0.13 mm | 100 Ω differential |
| USB | 0.117 mm | 0.13 mm | 90 Ω differential |
| RMII | 0.13 mm | — | 50 Ω single-ended |
| Power | 0.6 mm | — | — |
| Default | 0.2 mm | — | — |

Stitching vias surround the high-speed signals on F.Cu only. B.Cu carries just short layer
transitions of those signals, & its reference plane is In2.Cu.

JLCPCB's fabrication limits are encoded as custom DRC rules in
`luckfox_core3506_adapter.kicad_dru`. Track width & spacing minima are in **Board Setup →
Design Rules → Constraints** instead.

## Order from JLCPCB

> **NOTE:** the files in `production/` reproduce Revision A exactly, including the faults in
> [errata.md](errata.md). Boards built from them need the E1 & E2 reworks before USB host
> works.

The files were generated by the Fabrication Toolkit plugin
([JLC-Plugin-for-KiCad](https://github.com/bennymeg/JLC-Plugin-for-KiCad)) using
`fabrication-toolkit-options.json`, which excludes parts marked do-not-populate (DNP).

| File | Upload as |
|---|---|
| `production/luckfox_core3506_adapter.zip` | Gerbers & drill |
| `production/bom.csv` | Bill of materials |
| `production/positions.csv` | Component placement (CPL) |

Order Economic PCBA. JLCPCB does not assemble three parts, which are soldered by hand: J1
(HR911105A RJ45), H1 (2 × 20 pin header) & U1 (Core3506). JLCPCB rejected U1 for assembly.

### Correct the placement file

The toolkit exports with `AUTO TRANSLATE` (origin correction) on. Make these changes in
JLCPCB's placement preview after uploading `positions.csv`:

1. Remove U1 from the placement list.
2. Move H5 & H6 (USB-C, LCSC C2765186) by **+1.6 mm in Y**.
3. Rotate:

| Ref | Part | Rotation |
|---|---|---|
| J1 | HR911105A (RJ45) | +180° |
| T1 | SS8050 | +180° |
| T2 | MMBT3906 | +180° |
| T3 | SS8050 | +180° |
| Q5 | SI2301CDS | +180° |
| U5 | CH182H2 (Ethernet PHY) | −90° |
| R5 | 2.2 Ω array (4 × 0603) | +90° |
| R59 | 22 Ω array (4 × 0603) | +90° |

## ERC & DRC status

Observed with KiCad 10.0.6, its bundled libraries & the SparkFun library. Run from the project
directory:

```bash
kicad-cli sch erc luckfox_core3506_adapter.kicad_sch
kicad-cli pcb drc --schematic-parity luckfox_core3506_adapter.kicad_pcb
```

Where:
- `--schematic-parity` also compares the board against the schematic

Without the third-party libraries installed, both reports add one warning per part that uses
them (`lib_symbol_issues`, `footprint_link_issues`, `lib_footprint_issues`). Those warnings
concern the library tables only, not the design.

### ERC

| Report | Cause | Real fault |
|---|---|---|
| Power output connected to power output, `VCC_3V3` | The SoM PMIC drives `VCC_3V3` & a `PWR_FLAG` is also placed on it | No |
| J2 pin 4 (VDD) not driven | Supplied through Q5, which ERC does not treat as a source | No |
| `#PWR01` (GND) not driven | No `PWR_FLAG` on GND | No |
| 4 × `C_Small`, 1 × `Qwiic_Vertical` differ from library | The design copies differ from the current library versions | No |

### DRC

| Count | Report | Cause |
|---|---|---|
| 26 | Copper to board edge, U1 | Castellated SoM pads beside the cut-out; manufacturable |
| 16 | Silkscreen clipped by board edge, U1 | SoM outline overlaps the cut-out; the fab clips it |
| 8 | Hole clearance, H5 & H6 | USB-C GND pads 0.165 mm from the connector's locating holes; rule is 0.25 mm |
| 1 | Silkscreen text thickness | 40-pin header numbering is 0.1 mm, below the 0.15 mm rule |
| 6 | Footprint differs from library, ED9–ED14 | Board copies of `Diode_SMD:D_0402_1005Metric` differ from the current library |
| 0 | Schematic parity | |
| 0 | Unconnected items | |

The ESD diodes (D2, ED1–ED5, ED8–ED18) are DFN1006 parts on `D_0402_1005Metric` footprints.
The two land patterns are close — 0.59 × 0.64 mm pads at 0.97 mm pitch against 0.50 × 0.60 mm
at 0.80 mm for `D_DFN1006-2L` — & the 0402 pads cover the DFN1006 terminals. Revision A was
assembled on them.
